# יומן משתמשים

האפליקציה מדווחת פעם ביום לכל מכשיר לגיליון Google. נשלחים מזהה אקראי של המכשיר, השם שהמשתמש הגדיר (אם הגדיר) וסוג המכשיר. בגיליון יש שורה אחת לכל מכשיר, עם כניסה ראשונה, כניסה אחרונה ומספר ימי שימוש. העמודה "הערה" שלך בלבד, והסקריפט לא נוגע בה.

## התקנה (פעם אחת)

1. פותחים גיליון Google חדש, למשל בשם "הזמנת סרט - משתמשים".
2. בתפריט: **Extensions → Apps Script** (בעברית: תוספים ← Apps Script).
3. מוחקים את מה שכתוב בעורך ומדביקים את כל התוכן של `Code.gs`. שומרים (Ctrl+S).
4. למעלה, בתיבת הפונקציות, בוחרים `setup` ולוחצים **Run**. Google יבקש הרשאה:
   - Review permissions ← בוחרים את החשבון שלך.
   - אם מופיע "Google hasn't verified this app": **Advanced** ← **Go to ... (unsafe)**. זה הסקריפט שלך, בחשבון שלך.
   - Allow.
   בגיליון תיווצר לשונית "משתמשים" עם כותרות.
5. **Deploy → New deployment**. בגלגל השיניים בוחרים **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Deploy, ומעתיקים את ה-**Web app URL** (מסתיים ב-`/exec`).
6. בדיקה: פותחים את הכתובת בדפדפן. אמורה להופיע המילה "פועל".
7. ב-GitHub פותחים את `core/config.json`, לוחצים על העיפרון, מדביקים את הכתובת בין המירכאות:
   ```json
   { "usageLogUrl": "https://script.google.com/macros/s/.../exec" }
   ```
   ושומרים.

מהרגע הזה כל כניסה חדשה תופיע בגיליון, בדרך כלל תוך כמה שניות.

## שינוי בסקריפט אחרי ההתקנה

אחרי עריכה של `Code.gs` צריך לפרסם גרסה חדשה, אחרת הכתובת ממשיכה להריץ את הישנה:
**Deploy → Manage deployments** ← העיפרון ← Version: **New version** ← Deploy. הכתובת לא משתנה.

## כיבוי

מרוקנים את הכתובת ב-`core/config.json` (`"usageLogUrl": ""`). האפליקציה מפסיקה לדווח, וגם ההודעה על הרישום נעלמת ממסך ההגדרות.

## מגבלות

- זה רישום של **מכשירים**, לא של אנשים. מי שמנקה את הדפדפן או נכנס מטלפון אחר ייספר כמכשיר חדש.
- מי שלא הגדיר שם יופיע בלי שם. כדאי לכתוב בעמודה "הערה" מי זה (למשל לפי סוג המכשיר ותאריך הכניסה הראשונה).
- גלישה בסתר או דפדפן שחוסם אחסון: לא מדווחים בכלל, כדי לא לספור את אותו אדם שוב ושוב.
- הכתובת גלויה בקוד, כך שמישהו יכול לשלוח אליה שורות מזויפות. הוא לא יכול לקרוא את הגיליון או למחוק ממנו. בשלב 1, עם כניסה דרך Google, הרשימה תגיע מ-Firebase ותהיה אמינה.
